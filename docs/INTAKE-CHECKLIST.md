# Intake checklist (first meeting)

Copy into the client's repo as `docs/INTAKE.md` and fill in. Don't guess – write "ask" next to anything unknown.

## Business
- [ ] Business name exactly as on their site / signage
- [ ] Owner name, best phone, best email (and which email should get website messages)
- [ ] Who else may edit (e.g. spouse, office manager)? Their emails
- [ ] Any licence numbers, brokerage / franchise / association rules about what must appear on the site?

## Current website
- [ ] Current address: ______________________
- [ ] Who hosts it (Wix, Squarespace, Placester, GoDaddy, WordPress…): ______________ · renewal date: ______
- [ ] Login available? (needed to download photos/text if the site is hard to copy)
- [ ] Pages they **love** / pages they **never use** / anything wrong or out of date
- [ ] Forms on the old site (contact, quote request, booking)? Where do those messages go today?
- [ ] Anything else the old host provides: booking, online payments, listings feed, blog, chat widget, analytics

## Domain + email (most important)
- [ ] Domain registrar (GoDaddy, Namecheap, Google/Squarespace…): ______________ · expires: ______
- [ ] Who has the registrar login? 2-step verification on?
- [ ] Email on this domain? Provider (Google Workspace / Microsoft 365 / registrar email / none): ______________
- [ ] Any other services using the domain (e.g. `shop.`, `book.`, email marketing verification)?

## Content
- [ ] Photos: which ones do they **own** or have permission to use? (stock/agency/photographer?)
- [ ] Reviews: real, from clients, OK to show names/initials? Any newer reviews (Google, Zillow, Yelp…) to add?
- [ ] Logo + colors + fonts (or "match the current site")
- [ ] Social links

## What they'll change themselves
- [ ] Homepage slideshow? (y/n)  · Other photos (headshot, team, storefront, project photos)? Which?
- [ ] Reviews? (y/n)
- [ ] Contact form? (y/n) – messages go to: ______________
- [ ] Which computer will they edit on? (Windows/Mac laptop; phones are off by default)

## Accounts to set up (theirs, you're invited)
- [ ] Cloudflare account in **their** name (they invite you as Administrator)
- [ ] GitHub repo: yours (`<client>-site`), private
- [ ] Agreed: who pays for the domain, who to call if something breaks, what's included after launch
